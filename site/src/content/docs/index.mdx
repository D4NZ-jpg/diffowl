## Review automation with a boundary

Diffowl gives every eligible pull request a structured first pass. Reviewer, challenger, and verifier roles inspect the change, test the strength of candidate findings, and return one typed outcome. GitHub publication stays separate from review semantics, and unsafe or incomplete work never appears as clean.

:::caution[What “clean” means]
A clean outcome means the completed permitted review found no material findings. It is not proof of correctness, an approval, or a merge decision.
:::
