<section class="home-section proof">
  <div class="section-intro">
    <h2>Every finding shows its work.</h2>
    <p>
      A material finding is a claim with a location, an impact, repository evidence, and an explicit
      verification state. No evidence, no finding.
    </p>
  </div>
  <div>
    <div class="finding">
      <div class="finding-head">
        <span>src/webhook-queue.ts:118</span>
        <span class="state">verified</span>
      </div>
      <div class="finding-body">
        <strong>Deleting the retry guard drops queued webhooks on transient failures.</strong>
        <p>Transient provider errors now permanently discard events instead of requeueing them.</p>
        <div class="finding-evidence">
          <div class="del">{"- if (err.retriable && attempt < MAX_RETRIES) {"}</div>
          <div class="del">{"-   return this.requeue(event, attempt + 1);"}</div>
          <div class="del">{"- }"}</div>
          <div class="ctx">{"  this.deadLetter.push(event);"}</div>
        </div>
      </div>
      <div class="finding-foot">
        <span>
          Evidence: <b>scoped diff</b>
        </span>
        <span>
          Validation: <b>npm test failed on head</b>

<section class="home-section" id="how-it-works">
  <div class="section-intro">
    <h2>One review. Three safeguards.</h2>
    <p>
      Generation, challenge, and verification are separate roles, so confident language never counts
      as proof by itself.
    </p>
  </div>
  <div class="flow">
    <div class="flow-step">
      <i class="flow-dot"></i>
      <strong>Classify</strong>
      <span>Diffowl classifies trust before it starts risky work.</span>
    </div>
    <div class="flow-step">
      <i class="flow-dot"></i>
      <strong>Review</strong>
      <span>The reviewer grounds each candidate in the change and repository.</span>
    </div>
    <div class="flow-step">
      <i class="flow-dot"></i>
      <strong>Challenge</strong>
      <span>The challenger rejects weak evidence and low-materiality claims.</span>
    </div>
    <div class="flow-step">
      <i class="flow-dot"></i>
      <strong>Verify</strong>
      <span>Supported findings become a typed, auditable outcome.</span>
    </div>
  </div>
</section>
